## 3. Bugs / surprising lessons

- **Phase 3 bankroll bug.** Inconsistent placeholder-date filtering inflated whale traders' peaks by 5-7×. Surfaced by the bankroll point-in-time rebuild. Real, fixed. **Lesson:** when a metric depends on date-filter conditions, every CTE/branch must apply the same filter — silent inconsistency between branches biases the tail.
- **`phantom_position_score` baseline correction.** "1.0 = pure directional" was idealised framing — all six pools sit at 1.4-1.8 baseline. The metric is useful as *relative signal* (1.7 normal vs 8+ heavy arb) but not as an absolute threshold. **Lesson:** when a metric's theoretical floor is rarely observed, document the empirical floor before downstream code uses the theoretical one as a threshold.
- **In-sample cohort thresholds don't generalise across time.** Phase 4 thresholds were calibrated against the 2026 snapshot; broke for 2024 cohorts (B = 11 leaders/month, BC = 0 signals). **Lesson:** any absolute-threshold selection rule needs an OOS sanity-test before being applied historically. Fix pattern: percentile + floor + Top-K.
- **Indiscriminate copy drowns in slippage.** 270+ leaders → 80k signals/run → cost dominates. **Lesson:** signal-volume and edge-magnitude have to be matched against expected per-signal cost. Top-K is the canonical answer when the cohort-membership cardinality is large.
